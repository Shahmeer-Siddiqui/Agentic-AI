# 📚 AI Study Notes Generator

An AI-powered Study Notes Generator built using **LangGraph** and **OpenRouter**. It converts any topic into structured study notes through a sequential AI workflow.

## 🚀 Features

- Topic Explanation
- Key Points Extraction
- Quiz Generation
- Final Study Notes
- Sequential Workflow

## 🛠️ Tech Stack

- Python
- LangGraph
- LangChain
- Google Api Key

## ▶️ Run

```bash
pip install -r requirements.txt
python project.py
```

## 📂 Workflow

```text
Topic
  ↓
Explanation
  ↓
Key Points
  ↓
Quiz
```
