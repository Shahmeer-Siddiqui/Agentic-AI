# AI Software Architect

This project is an AI-powered Software Architect built using Python, LangGraph, LangChain, and Api Keys.

## Features

- Analyze software ideas
- Generate project requirements
- Extract software features
- Design system architecture
- Create database design
- Generate REST API plan
- Recommend technology stack
- Build development roadmap
- Export complete software blueprint as a Markdown file

## Technologies

- Python
- LangGraph
- Api Keys
- python-dotenv

## Run

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```
OPENROUTER_API_KEY=your_api_key_here
```

Run

```bash
python project.py
```
